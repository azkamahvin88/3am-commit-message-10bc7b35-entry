A deterministic Python program that writes one one-line git commit message — the funniest commit an AI coding agent might type at 3am after a long night of fixing its own bugs: "fix: 47 tabs open, 0 idea which one fixed it. closing them all and pretending this was planned" — to `/output/entry.txt` for make.fun's "The 3AM Commit Message" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed joke string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the joke was chosen from 16 candidates scored against the judge's brief.
